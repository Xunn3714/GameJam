# 羊群暴力扩张 Alpha

- 状态：实验玩法
- 场景：`Assets/_Game/Scenes/Dev/AlphaFlockExpansion.unity`
- 基线：保留现有 `Level_01` 羊群 MVP，不在本实验中修改集成 Scene

## 核心循环

玩家从一只羊开始。系统持续检查玩家周围的野生羊密度；数量不足时，根据已经解锁的最高阶段从镜头外补充羊群。玩家移动到新区域后，过远且未招募的羊会被移除，并在玩家周围重新补充。游戏不会因为达到某个羊数而结算，可以持续扩张。

| 历史最高羊数 | 每批生成 | 相机尺寸 | 狼 |
|---:|---:|---:|---|
| 1～4 | 1 | 5 | 不生成 |
| 5～19 | 2～3 | 7 | 不生成 |
| 20～49 | 5～7 | 10 | 开始生成 |
| 50～99 | 10～15 | 14 | 持续生成 |
| 100 及以上 | 20～30 | 18 | 持续生成 |

阶段以本局历史最高羊数判断，只能升级，不能降级。狼撞散或叼走羊之后，相机、批次规模和狼的解锁状态均不会回退。被撞散的旧成员重新加入时不计作新消耗的野生羊，因此不会额外抬高周边密度。

周围野生羊的密度目标根据当前相机尺寸计算，不固定为某个羊群点数量。当前参数约为每个相机尺寸单位维持 `2.5` 只野生羊，即五个阶段附近分别约有 `13 / 18 / 25 / 35 / 45` 只野生羊。补充时仍遵守当前阶段的单组大小。

## Alpha 范围

- WASD 控制羊群中心。
- 接触野生羊后自动加入。
- 新批次在当前镜头外、世界边界内生成。
- 动态生成的羊保持单局名字唯一；名称池耗尽后使用递增后备名。
- 达到 20 只后启动现有狼生成器。
- 继续使用现有狼的预警、冲锋、撞散和叼走规则。
- 使用开发 HUD 显示阶段、当前羊数、历史最高值、野生羊和狼状态。

本 Alpha 暂不接入正式任务、结算、图鉴、特殊羊或 `Level_01` UI。超过 100 只后的运动性能需要根据试玩结果继续优化。

## 场景生成

在 Unity 菜单运行：

`Game Jam → Alpha Flock Expansion → Setup Scene`

该命令可重复执行，只重建 Alpha 场景中由它管理的对象，不修改 `Level_01`、Prefab 或 Project Settings。
