- **关联技术方案**：[羊群 MVP 技术方案](<../tech docs/羊群MVP技术方案.md>)

## 1. 一句话概念

玩家控制一个最初只有 1 名成员的羊群，通过成员接触地图中随机分布的羊让对方加入，最终形成一个拥有名字和共同旅程记录的族群。游戏中没有固定头羊。

## 2. MVP 要验证什么

第一版只验证三个问题：

1. 从一只羊逐渐变成一群羊，过程是否有满足感。
2. 新成员加入时，名字、队伍变化和 UI 反馈是否足够明确。
3. “拉屎”能否作为简单、有辨识度的初始主动技能。

如果玩家愿意主动寻找最后一只羊，并且看到队伍扩大、结算成员名单时感到有趣，核心方向即成立。

## 3. 玩家流程

```text
进入 Level_01
→ 建立一个包含 1 只随机命名成员羊的族群
→ 看到按本局生成数量创建的任务列表
→ 使用 WASD 探索草地
→ 接触一只羊，对方加入族群
→ 显示该羊名称和任务进度
→ 使用 Space 拉屎
→ 完成全部必做招募任务
→ 查看本局统计、成员名单和图鉴
→ 返回主菜单
```

原始小地图目标单局时长为 3～5 分钟；当前 50 只羊、`100 × 50` 地图配置用于验证大地图生成和羊群规模，正式时长需要试玩后重新标定。

## 4. 确定的游戏规则

### 4.1 移动

- 游戏采用 2D 俯视角。
- 玩家使用 WASD 控制羊群中心移动，而不是控制某一只羊。
- 第一版不需要冲刺、攻击或交互键；人数障碍由接触时自动判断，不增加主动冲撞按键。
- 所有成员羊地位相同，围绕族群中心自动移动，不存在固定头羊。
- 成员持续通过避让、聚拢、速度趋同和低频游走形成动态羊群，不锁定固定相对位置。
- 羊群舒适区不是规则圆形：沿移动方向形成不规则长椭圆，成员越多长宽差与松散外沿越明显，停止后保留最后的整体朝向。
- 轻点方向键只做小幅位置调整，不应让转向从中心向外形成整齐波纹；持续转向时，成员在很短且与中心距离无关的错峰内完成翻面。
- 停止输入后关闭移动中的随机游走；成员先完成必要的避让和归群，再由少量已招募羊在停留点附近错峰左右踱步，其余成员稳定待机。

### 4.2 招募与随机分布

- 玩家开局控制一个拥有 1 名成员的族群。
- 每局按场景配置生成精确数量的待招募羊；`Level_01` 当前配置为 50 只。
- Scene 中已有的待招募羊只作为 Prefab/编辑参考，运行时会隐藏并生成一批新的羊，不与场景预摆数量叠加。
- 生成区域、总数、安全半径、间距和密度均可在 `MvpGameController` Inspector 中调整。
- 普通羊按 1、2、3 只为一组分布，当前权重为 `60 / 30 / 10`；最后不足一组时仍保证生成总数准确。
- 每个生成位依次按彩蛋 0.1%、金色 0.3%、紫色 1%、蓝色 5%、绿色 50% 判定品质；均未命中时为普通羊。
- 命中品质后只在该品质尚未出现的有效羊种中等概率抽取。同一种特殊羊单局最多出现一次；该品质为空或本局已抽完时，本次直接生成普通羊，不向其他品质降级。
- 特殊羊只能单只出现，不参与普通羊成组逻辑。当前美术池包含绿色品质的礼帽小羊、蝴蝶结小羊、山羊和黑色小羊；蓝色、紫色、金色和彩蛋品质暂为空，因此命中后会生成普通羊。
- 支持在地图中放置固定特殊羊点位；点位只决定已抽中特殊羊的位置，不指定羊种。
- 任意族群成员接触待招募羊后，对方立即加入族群，不需要按键。
- 每只羊只能被招募一次。
- 任务目标由本局实际成功生成的羊数决定，不写死为 5。
- 族群数量包含初始成员。
- 第一版没有失败条件，也不会主动触发成员丢失；数据模型允许后续移除成员，而不依赖某个特定成员存活。

### 4.3 随机名称

- 初始成员羊和本局生成的所有待招募羊在每局开始时获得名称。
- 单局内名称不重复。
- 名称只在加入提示和最终成员名单中显示，不常驻羊的头顶。
- 重新开始后重新随机。
- 名称不跨局保存。

初始名称池建议：

```text
棉花糖、云朵、小卷、豆豆、奶盖、白团
咩咩、毛球、盐巴、小雪、软糖、月亮
```

名称池不足时使用 `小羊 01`、`小羊 02` 等后备名称。

### 4.4 人数障碍

- 场景放置一个简单长方形障碍。
- 族群数量不超过 5 时，羊群中心无法穿过，碰撞时障碍短暂变红。
- 族群数量大于 5 时，任意成员或羊群中心撞到障碍都会将其破坏。
- 障碍只验证“壮大族群后解锁道路”的反馈，不加入伤害、耐久或复杂破坏动画。

### 4.5 拉屎技能

- 按键：Space。
- 开局立即可用。
- 冷却时间：2 秒。
- 使用成功后在羊身后生成一坨粪便。
- 粪便存在10秒，场上最多同时存在10个。
- 冷却中、暂停时或游戏完成后不能使用。
- 第一版粪便没有伤害、减速或施肥效果。

该功能目前用于测试主动技能的基本体验：按键、生成、反馈、冷却和统计。生态效果留给后续版本。

## 5. UI 与文案

### 5.1 常驻 HUD

```text
找到羊：0/5
族群：1
Space：拉屎
```

冷却时将技能提示改为：

```text
拉屎：1.4秒
```

### 5.2 加入反馈

招募成功后显示约1.5秒：

```text
“棉花糖”加入了族群！
```

同时应有至少一种非文字反馈：简单音效、缩放、高亮或粒子。

### 5.3 完成与结算

完成全部必做任务后显示：

```text
羊群集合完毕！

当前羊数：51
成功招募：50
当前分数：50
拉屎次数：12
游戏用时：01:43
本局同伴：云朵、豆豆、奶盖……

[返回标题]
```

第一版统计字段固定为：

- 族群规模。
- 成功招募数量和当前分数。
- 成员名单。
- 成功拉屎次数。
- 游戏用时。

暂停时间不计入游戏用时，冷却期间的无效按键不计入拉屎次数。

## 6. 场景设计

第一版使用 `Level_01`。当前原型生成区域为 `100 × 50` 个世界单位，相机可视范围约 10 个世界单位；背景、玩家移动边界和相机边界随生成区域同步配置。

普通羊群之间保留最小距离，同时避开玩家出生安全区和 Collider。特殊羊默认在同样的有效区域中单独随机放置；需要剧情或地标控制时使用固定特殊羊点位。场景使用树、石头、草丛或围栏引导路线，但不设置会卡住跟随羊的狭窄通道。

### 6.1 当前特殊羊美术

| 类型 | 当前表现 | 生成规则 |
|---|---|---|
| 普通羊 | 白色普通羊 | 1～3 只成组 |
| 礼帽小羊 | 黑色礼帽 | 绿色品质，单局至多一次 |
| 蝴蝶结小羊 | 红色蝴蝶结 | 绿色品质，单局至多一次 |
| 山羊 | 羊角 | 绿色品质，单局至多一次 |
| 黑色小羊 | 黑色羊毛 | 绿色品质，单局至多一次 |

特殊能力尚未确定。现阶段这些 Prefab 只负责外观区分和特殊羊身份标记，不提前写能力框架。

## 7. 体验节奏

| 阶段 | 玩家感受 | 主要反馈 |
|---|---|---|
| 开局 | 孤单、目标明确 | 只有一只羊，提示寻找同伴 |
| 第一次招募 | 立即理解规则 | 名称提示、数量变化、开始跟随 |
| 中段 | 族群逐渐壮大 | 队伍视觉变大，可随时拉屎 |
| 最后一只羊 | 有寻找目标 | 任务进度接近完成 |
| 结算 | 形成一次小旅程 | 成员名单和本局统计 |

## 8. MVP 验收标准

- 新玩家不看外部说明也能理解 WASD 移动和寻找羊的目标。
- 第一次接触羊时能明确感知“它加入了我”。
- 玩家能分辨任务进度和族群总数的区别。
- 羊群扩大后具有明显的视觉满足感。
- 玩家知道 Space 可以拉屎，并能理解冷却状态。
- 找齐本局生成的全部羊后能看到正确的成员名单与统计。
- 修改生成总数后，实际羊数、任务目标和结算会同步变化。
- 普通羊按 1～3 只群组出现，单只组概率最高、三只组概率最低。
- 特殊品质概率符合配置；特殊羊只单独出现且同一种单局不重复，空品质或抽空品质回退为普通羊。
- 当前大地图配置能够完成完整闭环；正式时长和末期找羊体验需继续试玩调优。

## 9. 第一版不做

- 主动冲撞、战斗及其他群体技能。
- 牛、猴子或其他动物。
- 生老病死、繁殖、疾病、饥饿。
- 随机事件和复杂生态系统。
- 战斗、敌人和失败条件。
- 多关卡、人类相遇和分支结局。
- 名称自定义、本地化和跨局保存。
- 排行榜、成就和长期统计。

## 10. 后续评估方向

完成 MVP 试玩后再决定：

- 羊越多时解锁的第一个群体能力是什么。
- 拉屎是否发展为施肥、减速或路线标记。
- 是否加入食物、疾病和死亡压力。
- 第二个物种应选择牛还是猴子。
- 完成 Level_01 后是否进入 Ending。

这些内容不应提前进入第一版实现范围。
