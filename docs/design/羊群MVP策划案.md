# 《找到另一只羊》MVP 策划案

- **状态**：Draft
- **Owner**：TBD（策划）
- **最后更新**：2026-09-04
- **关联技术方案**：[羊群 MVP 技术方案](<../tech docs/羊群MVP技术方案.md>)
- **Agent 入口**：[`AGENTS.md`](../../AGENTS.md)

## 1. 一句话概念

玩家从一只孤单的羊开始，通过接触其他羊，让它们加入并跟随自己，最终形成一个拥有名字和共同旅程记录的小族群。

## 2. MVP 要验证什么

第一版只验证三个问题：

1. 从一只羊逐渐变成一群羊，过程是否有满足感。
2. 新成员加入时，名字、队伍变化和 UI 反馈是否足够明确。
3. “拉屎”能否作为简单、有辨识度的初始主动技能。

如果玩家愿意主动寻找最后一只羊，并且看到队伍扩大、结算成员名单时感到有趣，核心方向即成立。

## 3. 玩家流程

```text
进入 Level_01
→ 获得一只随机命名的玩家羊
→ 看到任务“找到另外 5 只羊”
→ 使用 WASD 探索草地
→ 接触一只羊，对方加入族群
→ 显示该羊名称和任务进度
→ 使用 Space 拉屎
→ 找齐 5 只羊
→ 查看本局统计和成员名单
→ 重新开始或返回主菜单
```

预计单局时长为 3～5 分钟。

## 4. 确定的游戏规则

### 4.1 移动

- 游戏采用 2D 俯视角。
- 玩家使用 WASD 控制领头羊移动。
- 第一版不需要冲刺、攻击、冲撞或交互键。
- 其他羊加入后自动跟随，不由玩家分别控制。

### 4.2 招募

- 玩家开局拥有 1 只羊。
- 场景中放置 5 只待招募羊。
- 玩家羊接触待招募羊后立即完成招募，不需要按键。
- 每只羊只能被招募一次。
- 任务进度统计新找到的羊，范围为 `0/5` 至 `5/5`。
- 族群数量包含玩家羊，范围为 1 至 6。
- 第一版没有失败条件，羊不会死亡或离队。

### 4.3 随机名称

- 玩家羊和 5 只待招募羊在每局开始时获得名称。
- 单局内名称不重复。
- 名称只在加入提示和最终成员名单中显示，不常驻羊的头顶。
- 重新开始后重新随机。
- 名称不跨局保存。

初始名称池建议：

```text
棉花糖、云朵、小卷、豆豆、奶盖、白团
咩咩、毛球、盐巴、小雪、软糖、月亮
```

名称池不足时使用 `小羊 01`、`小羊 02` 等后备名称。

### 4.4 拉屎技能

- 按键：Space。
- 开局立即可用。
- 冷却时间：2 秒。
- 使用成功后在羊身后生成一坨粪便。
- 粪便存在10秒，场上最多同时存在10个。
- 冷却中、暂停时或游戏完成后不能使用。
- 第一版粪便没有伤害、减速或施肥效果。

该功能目前用于测试主动技能的基本体验：按键、生成、反馈、冷却和统计。生态效果留给后续版本。

## 5. UI 与文案

### 5.1 常驻 HUD

```text
找到羊：0/5
族群：1
Space：拉屎
```

冷却时将技能提示改为：

```text
拉屎：1.4秒
```

### 5.2 加入反馈

招募成功后显示约1.5秒：

```text
“棉花糖”加入了族群！
```

同时应有至少一种非文字反馈：简单音效、缩放、高亮或粒子。

### 5.3 完成与结算

找齐第5只羊后显示：

```text
你找到了所有羊！

族群规模：6
拉屎次数：12
游戏用时：01:43
成员：云朵、豆豆、奶盖、白团、毛球、小雪

[重新开始]  [返回主菜单]
```

第一版统计字段固定为：

- 族群规模。
- 成员名单。
- 成功拉屎次数。
- 游戏用时。

暂停时间不计入游戏用时，冷却期间的无效按键不计入拉屎次数。

## 6. 场景设计

第一版使用 `Level_01`，玩法区域约为20×14个世界单位。

建议位置：

| 对象 | 参考坐标 | 作用 |
|---|---|---|
| 玩家羊 | `(0, 0)` | 开局位置 |
| 羊1 | `(-4, 2)` | 最容易发现，教学招募 |
| 羊2 | `(4, 3)` | 引导向右上探索 |
| 羊3 | `(-6, -3)` | 引导向左下探索 |
| 羊4 | `(6, -2)` | 较远目标 |
| 羊5 | `(1, 6)` | 最后探索区域 |

场景使用树、石头、草丛或围栏引导路线，但不设置会卡住跟随羊的狭窄通道。最后一只羊不能隐藏得过深。

## 7. 体验节奏

| 阶段 | 玩家感受 | 主要反馈 |
|---|---|---|
| 开局 | 孤单、目标明确 | 只有一只羊，提示寻找同伴 |
| 第一次招募 | 立即理解规则 | 名称提示、数量变化、开始跟随 |
| 中段 | 族群逐渐壮大 | 队伍视觉变大，可随时拉屎 |
| 最后一只羊 | 有寻找目标 | 任务进度接近完成 |
| 结算 | 形成一次小旅程 | 成员名单和本局统计 |

## 8. MVP 验收标准

- 新玩家不看外部说明也能理解 WASD 移动和寻找羊的目标。
- 第一次接触羊时能明确感知“它加入了我”。
- 玩家能分辨任务进度和族群总数的区别。
- 羊群扩大后具有明显的视觉满足感。
- 玩家知道 Space 可以拉屎，并能理解冷却状态。
- 找齐5只羊后能看到正确的成员名单与统计。
- 一局能够在5分钟左右完成，不因找不到最后一只羊而长时间停滞。

## 9. 第一版不做

- 冲撞及其他群体技能。
- 牛、猴子或其他动物。
- 生老病死、繁殖、疾病、饥饿。
- 随机事件和复杂生态系统。
- 战斗、敌人和失败条件。
- 多关卡、人类相遇和分支结局。
- 名称自定义、本地化和跨局保存。
- 排行榜、成就和长期统计。

## 10. 后续评估方向

完成 MVP 试玩后再决定：

- 羊越多时解锁的第一个群体能力是什么。
- 拉屎是否发展为施肥、减速或路线标记。
- 是否加入食物、疾病和死亡压力。
- 第二个物种应选择牛还是猴子。
- 完成 Level_01 后是否进入 Ending。

这些内容不应提前进入第一版实现范围。
