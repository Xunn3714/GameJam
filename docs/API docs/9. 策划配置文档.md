# 策划配置文档

> **Status: Draft**
> **Owner: TBD（策划）**
> **Last updated: 2026-09-04**

羊群 MVP 不建立通用配置加载框架。当前配置如下：

| 配置 | 编辑者 | 读取者 | 默认值 | 校验规则 | 运行时可变 |
|---|---|---|---|---|---|
| 招募目标 | 策划 | RecruitSheepTask | 5 | 大于0且不超过场景羊数 | 否 |
| 羊名称池 | 策划/文案 | SheepNameGenerator | 至少12个名称 | 去空、去重，不足时生成后备名 | 否 |
| 玩家速度 | 策划/程序 | SheepPlayerController | 4 | 大于0 | 否 |
| 跟随速度 | 策划/程序 | SheepFollower | 4.5 | 大于0 | 追赶时临时变化 |
| 拉屎冷却 | 策划 | PoopAbility | 2秒 | 大于等于0 | 否 |
| 粪便寿命 | 策划 | PoopAbility | 10秒 | 大于0 | 否 |
| 粪便数量上限 | 策划 | PoopAbility | 10 | 大于0 | 否 |

- 名称池使用只读 `SheepNamePool` ScriptableObject。
- 任务进度、随机名称和本局统计使用普通运行时 C# 对象。
- 不使用 ScriptableObject 保存可变的跨局状态。
- 数值调整后必须同步[策划案](<../design/羊群MVP策划案.md>)和[技术方案](<../tech docs/羊群MVP技术方案.md>)。
