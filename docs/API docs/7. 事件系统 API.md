# 事件系统 API

> **Status: Draft**
> **Owner: TBD**
> **Last updated: 2026-09-04**

当前不建立全局 Event Bus。羊群 MVP 只需要以下类型化窄事件：

```csharp
FlockController.SheepRecruited(RecruitableSheep sheep, int recruitedCount);
RecruitSheepTask.ProgressChanged(int current, int target);
RecruitSheepTask.Completed();
PoopAbility.Pooped();
```

- `MvpGameController` 负责订阅并协调任务、统计与 UI。
- 事件在 `OnEnable` 订阅、`OnDisable` 取消订阅，避免重复回调。
- UI 不直接订阅物理碰撞。
- 如果实现时签名发生变化，以测试通过的实际实现和同步更新后的技术方案为准。
