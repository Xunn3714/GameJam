羊群 MVP 已确定的 Prefab 以[策划案](<../design/羊群MVP策划案.md>)和[技术方案](<../tech docs/羊群MVP技术方案.md>)为准：

| Prefab | 核心组件/职责 | MVP 验收标准 |
|---|---|---|
| `SheepMember.prefab` | Rigidbody2D、羊身份、动态羊群转向 | 可由族群登记或移除；静止时不抖动；无 Missing Reference |
| `RecruitableSheep.prefab` | 羊身份、待招募状态、入群行为 | 名称非空；只能加入一次；加入后自然并入族群；无 Missing Reference |
| `Poop.prefab` | 拉屎技能生成物和自动销毁 | 生成位置正确；10秒后销毁；场上数量受限 |

WASD、镜头和 Space 技能绑定在场景中的 `SheepFlock` 逻辑对象上，不绑定某一只成员羊。

当前仓库实际目录拼写为 `Assets/_Game/Content/Perfabs/`。更名由 owner 在 Unity 中统一处理；在此之前不要创建并行的 `Prefabs/`。

下面的通用 Prefab 是早期候选，不属于当前 MVP 范围，不能作为实现任务自动生成。

#### 1. 核心与通用 Prefab

| 模块         | Prefab 名称               | 核心组件/职责                        | 验收标准                                              |
| ---------- | ----------------------- | ------------------------------ | ------------------------------------------------- |
| **Boot**   | `GameBootstrap.prefab`  | 挂载所有全局单例管理器                    | 拖入空场景，运行后所有 Manager 正常初始化，不报错，能自动跳转主菜单。           |
| **UI**     | `UIRoot.prefab`         | Canvas, EventSystem, UIManager | 适配 1920x1080 和 1280x720，UI 不模糊，包含主菜单/暂停/HUD的占位面板。 |
| **UI**     | `HUD_Panel.prefab`      | 玩家血条、能量条、提示文本                  | 能通过事件监听更新数值，不直接 `Find` 玩家对象。                      |
| **VFX**    | `VFX_Hit.prefab`        | 受击闪光、粒子、自动销毁                   | 播放完毕自动回收到对象池，不泄漏内存。                               |
| **Shared** | `InteractPrompt.prefab` | 交互提示 UI (如按 'E' 交互)            | 靠近可交互物体时平滑浮现，离开时消失。                               |

#### 2. SideView Kit (侧视角)

| 模块         | Prefab 名称                   | 核心组件/职责                      | 验收标准                              |
| ---------- | --------------------------- | ---------------------------- | --------------------------------- |
| **Player** | `Player_SideView.prefab`    | RB2D, 侧视控制器, 状态机, 碰撞体        | 能跑、跳、二段跳、下落加速；有土狼时间和跳跃缓冲；撞墙不卡住。   |
| **Camera** | `CameraRig_SideView.prefab` | Cinemachine 或 自定义跟随, 边界限制    | 平滑跟随玩家，到达地图边缘不穿帮，受击时能触发轻微震屏。      |
| **Enemy**  | `Enemy_Slapper.prefab`      | 基础巡逻AI, IDamageable 接口       | 能在平台上巡逻，边缘不掉下去；受击扣血并闪红，死亡播放特效并销毁。 |
| **Level**  | `Platform_OneWay.prefab`    | Tilemap/EdgeCollider, 单向平台脚本 | 玩家能从下往上跳穿，能按“下+跳”掉落。              |

#### 3. TopDown Kit (俯视角)

| 模块           | Prefab 名称                  | 核心组件/职责                             | 验收标准                                    |
| ------------ | -------------------------- | ----------------------------------- | --------------------------------------- |
| **Player**   | `Player_TopDown.prefab`    | RB2D(Kinematic/Dynamic), 8向移动, 朝向控制 | 移动平滑不穿墙；松开按键立刻停止(无惯性)；4向/8向动画切换正确。      |
| **Camera**   | `CameraRig_TopDown.prefab` | 跟随, 区域边界限制                          | 玩家居中，到达地图边缘相机停止移动，无像素抖动。                |
| **Interact** | `Interactor_Area.prefab`   | 玩家前方的检测 Trigger / OverlapCircle     | 玩家面朝物体时高亮提示，按交互键能触发 `IInteractable` 接口。 |
| **NPC**      | `NPC_Dummy.prefab`         | IInteractable 接口, 对话触发器             | 玩家靠近出现提示，按键后弹出对话框 UI 并暂停玩家移动。           |
| **Level**    | `Obstacle_Tree.prefab`     | 带有阻挡碰撞体的场景物件                        | 玩家无法穿过，但不会卡住移动逻辑。                       |
