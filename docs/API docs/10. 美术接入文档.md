# 美术接入文档

> **Status: Draft**
> **Owner: TBD（美术管线）**
> **Last updated: 2026-09-04**

羊群 MVP 至少需要以下2D资产：

- 通用成员羊 Sprite。
- 可招募羊 Sprite；第一版可以与成员羊共用，通过颜色区分待招募状态。
- 粪便 Sprite。
- 简单网格背景和人数障碍；当前原型由 Unity 内生成的网格与长方形 Sprite 提供。
- 草地和少量树木、石头或围栏占位图。
- 加入和完成的简单反馈素材（可先用缩放或颜色变化）。

建议路径：

```text
Assets/_Game/Content/Art/Characters/Sheep/
Assets/_Game/Content/Art/Environment/
Assets/_Game/Content/Art/UI/
```

当前 `Assets/Editor/PixelArtImporter.cs` 只匹配路径中包含 `Art/Sprites` 的图片，上述现有目录不会自动套用规则。修正导入器前，手动设置：

- Texture Type：Sprite。
- Filter Mode：Point。
- Compression：None/Uncompressed。
- Generate Mip Maps：关闭。
- Pixels Per Unit：16。

是否调整导入器由美术管线 owner 决定；不要为羊群任务顺手重构全项目美术目录。
