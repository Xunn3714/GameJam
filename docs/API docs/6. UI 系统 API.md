# UI 系统 API

> **Status: Draft**
> **Owner: TBD**
> **Last updated: 2026-09-04**

羊群 MVP 复用 `Level_01` 的现有 `GameCanvas` 和 EventSystem，不新增全局 UI Manager，也不创建第二个 EventSystem。

需要增加：

- `SheepHUD`：任务进度、族群数量、拉屎技能状态。
- `JoinToast`：显示 `“{羊名}”加入了族群！`。
- `ResultPanel`：显示族群规模、成员名单、拉屎次数和游戏用时。
- 重新开始和返回主菜单按钮。

UI 只接收数据并显示，不使用 `Find` 查找玩家。推荐窄接口：

```csharp
void MvpHudView.SetTaskProgress(int current, int target);
void MvpHudView.SetFlockCount(int count);
void MvpHudView.SetPoopCooldown(float remainingSeconds);
void JoinToastView.ShowJoined(string sheepName);
void ResultPanelView.Show(MvpSessionStats stats);
```

Canvas 继续使用 `Scale With Screen Size`、1920×1080、Match 0.5。具体文案见[策划案](<../design/羊群MVP策划案.md>)。
