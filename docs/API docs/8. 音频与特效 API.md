羊群 MVP 复用现有：

```csharp
AudioManager.Instance.PlaySFX(AudioClip clip);
```

第一版候选 SFX：

- 羊加入族群。
- 拉屎成功。
- 找齐5只羊。

音频为空或直接运行 Dev Scene、`AudioManager.Instance` 不存在时，玩法仍应正常运行。第一版不修改 AudioManager、不新增混音器、不建立对象池。

视觉反馈只需要：

- 羊加入时短暂缩放、高亮或简单粒子三选一。
- 拉屎时生成 `Poop.prefab`。
- 完成时显示结算面板。

正式音频与美术未交付前允许使用占位资源，但不得把占位资源写死在代码中。
