# 关卡与交互 API

> **Status: Draft**
> **Owner: TBD**
> **Last updated: 2026-09-04**

当前 MVP 关卡为 `Assets/_Game/Scenes/Level_01.unity`，玩法是族群成员接触并招募另外5只羊。

已确定的窄交互：

```csharp
public bool RecruitableSheep.TryRecruit(FlockController flock);
public bool FlockController.TryRecruit(RecruitableSheep sheep);
public bool FlockController.Remove(SheepMember member);
public void FlockController.RejectCurrentMovement();
```

- 招募由任意已登记成员羊的2D接触触发，不需要按交互键。
- 每只羊只能成功加入一次。
- 招募通过组件检测，不使用对象名称、Tag或全局 `IInteractable`。
- 第一版不建立通用交互框架。
- `FlockSizeObstacle` 在族群不足 6 只时拒绝当前移动，达到 6 只后接触即破坏。
- 功能先在个人 Dev Scene 或 `TestLevel` 验证，再由 `Level_01` owner 集成。

玩法规则见[羊群 MVP 策划案](<../design/羊群MVP策划案.md>)，完整组件关系见[技术方案](<../tech docs/羊群MVP技术方案.md>)。
